# Security policy

Do not open a public issue for credentials, personal data, dependency compromise, or a
vulnerability that could expose another contributor's system. Use GitHub's private
vulnerability-reporting interface for this repository. If that interface is unavailable,
contact the repository owner through their GitHub profile without including exploit or
secret material in a public message.

For mathematical errors, reproducibility failures, or incorrect research claims, use a
public correction or review issue. Those are part of the scientific record rather than
security vulnerabilities.
