# v0.1.0 — community-ready research snapshot

**Prepared:** 2026-09-05

This first public snapshot turns the repository into an openly licensed,
community-oriented research record. It does not claim a proof or disproof of the
Riemann hypothesis.

## Research included

- Revised Fourier-rigidity records and the corrected L8 statement.
- L9: a written singleton theorem for the fixed-background positive-comb class.
- L10: a written Davenport-Heilbronn completion and signed-comb explicit formula.
- A same-agent adversarial audit and additional deterministic numerical calibration.
- The earlier attempts, counterexamples, failed approaches, and reproducible outputs.

## Community infrastructure

- Apache-2.0 license, citation metadata, governance, contribution rules, and conduct
  and security policies.
- A public claim index with evidence states and explicit review gaps.
- Issue forms and a pull-request checklist for review, reproduction, correction, and
  new research.
- Quick CI, local-link validation, a secret-format audit, and documented reproduction
  commands.
- A researched path to Tao's IEANTN project and a ready scope proposal for L8a.

## Validation

The release candidate must pass:

```sh
python3 scripts/audit_repo.py
python3 scripts/verify.py --quick
python3 scripts/verify.py --explicit-formula
```

Any numerical output remains `NUMERICAL` unless a separate interval certificate is
provided. L8–L10 remain `PROVED-WRITTEN` pending independent human review.
